# Как поднять OrgDiff: инструкция для администратора

Всё, что нужно, лежит в этой папке. Английское описание проекта для жюри: [README.md](README.md).

**Нужно:** Docker с Compose v2 (Docker Desktop 4.x или Docker Engine 24+).
Больше ничего: ни Python, ни ключей.

## Вариант 1. Docker, три команды

```bash
git clone https://github.com/BAITC-Hacks/hack-5e5a1903-mg-ai.git
cd hack-5e5a1903-mg-ai/check-theory-kazakhtelecom
cp .env.example .env
docker compose up -d --build
```

Первая сборка около минуты. Открыть **http://localhost:8765**.

Проверка, что поднялось:

```bash
curl localhost:8765/health
# {"status":"ok","model":"gpt-4.1-mini","llm":false,"jobs_running":0}
```

Остановить: `docker compose down`. Результаты анализов и кеш лежат в томе
`orgdiff-cache` и переживают перезапуск. Удалить всё вместе с томом:
`docker compose down -v`.

## Ключ OpenAI, по желанию

Без ключа сервис работает: находит изменения структуры, полные потери функций,
переносы и дубли по близости текстов. С ключом включаются проверка спорных мест
моделью, частичные потери с цитатами, вердикты по конфликту интересов и рекомендации.

Чтобы включить, вписать ключ в `.env`:

```
OPENAI_API_KEY=sk-...
```

и перезапустить: `docker compose up -d`. Один анализ контрольного комплекта стоит
около $0.06 и идёт около 3 минут. Наружу уходят только тексты пунктов, никогда
документ целиком.

## Если порт 8765 занят

В `.env` поменять `ORGDIFF_PORT=8765` на свободный, например `ORGDIFF_PORT=8080`,
затем `docker compose up -d`. Сервис будет на `http://localhost:8080`.

## Как пользоваться

1. На главной странице две зоны: комплект «до» и комплект «после». Перетащить файлы
   `.docx`, `.pdf`, `.xlsx` в любой комбинации, по нескольку на каждую сторону.
2. Для демонстрации нажать **«Взять контрольный комплект организаторов»**: файлы
   подставятся сами (положение о внутреннем аудите, редакции 8 и 9, плюс таблицы
   оргструктуры).
3. Нажать **«Сравнить документы»**. Без ключа отчёт готов через 10–15 секунд,
   с ключом через 3 минуты; страница ожидания показывает этапы и счётчик обращений.
4. В отчёте: изменения структуры, потери функций, переносы, дубли, конфликты
   интересов. Каждая ссылка «до, п. 5.6.2» открывает пункт в документе.
   Кнопка «скачать заключение» отдаёт `.docx`, рядом `result.json`.

Что должно быть в отчёте на контрольном комплекте: созданы ДИТААД и ДОА, сохранены
ДККМ и ДНМ, упразднена должность «Директор направления внутреннего аудита», потеряны
функции 5.6.2, 5.6.3, 5.7.2, перенос 5.4.4 → 5.3.3, дубли 5.3.6 ~ 5.4.3,
5.3.12 ~ 5.4.9, 5.3.8 ~ 5.4.5, конфликт интересов в п. 4.4.

## Вариант 2. Без Docker

Нужен Python 3.12 и [uv](https://docs.astral.sh/uv/getting-started/installation/).

```bash
cd check-theory-kazakhtelecom
uv sync
uv run app.py
```

Сервис на http://localhost:8765. Ключ так же читается из `.env` в этой папке.

Проверить, что всё работает:

```bash
uv run pytest -q              # 40 тестов, без ключа 39 проходят и 1 пропускается
uv run run.py --mode tfidf    # контрольный прогон, печатает "GOLDEN lexical 16/16"
```

## Переменные окружения

Все в [.env.example](.env.example), значения по умолчанию работают без правок.

| Переменная | Что значит | По умолчанию |
|---|---|---|
| `OPENAI_API_KEY` | ключ OpenAI, пусто значит без модели | пусто |
| `ORGDIFF_MODEL` | модель для проверки и рекомендаций | `gpt-4.1-mini` |
| `ORGDIFF_LLM_TIMEOUT` | таймаут одного обращения к модели, секунды | `60` |
| `ORGDIFF_PORT` | порт на хосте для Docker Compose | `8765` |

## Типичные проблемы

| Симптом | Что сделать |
|---|---|
| `port is already allocated` | поменять `ORGDIFF_PORT` в `.env` и `docker compose up -d` |
| `/health` отвечает `"llm":false` при заданном ключе | ключ вписан после запуска: `docker compose up -d` ещё раз |
| «ключ OpenAI отклонён» в отчёте | ключ неверный или без средств; убрать его из `.env`, сервис работает без модели |
| «неподдерживаемый формат» при загрузке | принимаются только `.docx`, `.pdf` с текстовым слоем и `.xlsx`; сканы без текста не читаются |
| «сервер был перезапущен во время анализа» | контейнер перезапустился в середине задачи, запустить анализ заново |
| Долго висит «Проверка спорных мест моделью» | нормально с ключом, до 3 минут; счётчик обращений должен расти |

Инструкция проверена на свежем клоне `main`: `uv sync`, 39 тестов без ключа,
контрольный прогон 16/16 и сборка образа прошли с первого раза.
