# .dev-notes

Личные заметки каждого разработчика. Три человека: dev1, dev2, dev3.

## Как это работает

- `me.md` — **кто ты**. Файл в `.gitignore`, у каждого свой. Claude читает его через CLAUDE.md и понимает, за какого dev работает.
  Скопируй `me.example.md` в `me.md` и впиши свой номер.
- `dev1.md`, `dev2.md`, `dev3.md` — заметки каждого dev, общие для команды (коммитятся). Что делал, что сломано, что нужно от других.
- `worktrees.md` — реестр живых worktree и занятых портов. Создал worktree → добавил строку. Смерджил PR → удалил строку и освободил порты.
- Архитектурные вещи сюда не пишем, они идут в `docs/`.
