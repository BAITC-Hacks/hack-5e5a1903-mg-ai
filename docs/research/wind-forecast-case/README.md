# Исследование кейса: прогноз выработки ВЭС

Материалы по нашему кейсу HackAlem AI: «Agentic AI для прогнозирования выработки ВЭС».
**Это выбранный кейс команды.** Что сдаем и чекбоксы готовности: [../../../GOAL.md](../../../GOAL.md).
Зафиксированные решения, контракт между модулями и задачи:
[issue #2](https://github.com/BAITC-Hacks/hack-5e5a1903-mg-ai/issues/2).
Материалы получены 2026-09-23. Часть предложений в них уже отвергнута решениями
из issue #2, например LightGBM и GRIB через Herbie: при расхождении верен issue #2.

| Файл | Что внутри |
|---|---|
| [00-brief.md](00-brief.md) | Бриф кейса: условие, критерии, объект (ВЭС «Шелек»), ловушки с утечкой погоды из будущего, источники архивных прогнозов |
| [round1-architect.md](round1-architect.md) | Техническое решение под окно в 4 часа: as-of-хранилище, LightGBM, агент как state machine, план по часам |
| [round1-critic.md](round1-critic.md) | Разбор глазами жюри: формат хакатона, run-gate, что сделают 80% команд, ценность в цифрах, каверзные вопросы |
| [round1-visionary.md](round1-visionary.md) | Пять концепций решения и выбор топ-1: «Заявка к 08:00» на фундаменте «Машины времени» |
| [dashboard/](dashboard/) | Интерактивный прототип дашборда ZHEL.ai на синтетических данных: [PROJECT.md](dashboard/PROJECT.md) с описанием, две HTML-версии и `support.js` |

Дашборд открывается локально в браузере: файл `dashboard/ZHEL Forecast.dc.html`.
Он подтягивает React и Babel с unpkg и шрифты с Google Fonts, поэтому нужен интернет.
