## Зоны ответственности

- **dev1** — агент и центральный backend. Принимает запрос на прогноз, берет данные у dev3,
  отправляет их в модель dev2, анализирует ответ, публикует выпуск и отдает его интерфейсу.
  Итоговая интеграция и README тоже за dev1.
- **dev2** — только модель. Отдельный сервис `ml` со Swagger-контрактом, обучение на LightGBM.
  Данные сам не собирает: получает готовые строки погоды в запросе и отвечает P10/P50/P90.
- **dev3** — все входные данные. Сам выбирает источник погоды, отдает погоду строго на момент
  прогноза, историю турбин и проверенный часовой пояс.
